═══════════════════════════════════════════════════════════════════════════
                            HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

FLOW:
─────
User Query 
    → LLM Agent (proposes database query)
    → DataFence Security (enforces policies)
    → Database Connector (executes safe query)
    → DataFence Validation (protects results)
    → Protected Response

SECURITY LAYERS (7 layers of protection):
──────────────────────────────────────────
1. Authorization - Who can access what
2. Resource Validation - Resource exists and allowed
3. Field-Level Security - Column access control (allow/redact/deny)
4. Row-Level Security - Tenant isolation, custom filters
5. SQL Firewall - SQL injection prevention
6. PII Detection - Detect and redact sensitive data
7. Result Validation - Verify and generate evidence

═══════════════════════════════════════════════════════════════════════════
                        EXAMPLE SCENARIO
═══════════════════════════════════════════════════════════════════════════

USER ASKS:
──────────
"Show me John Doe's account including SSN and credit card"

LLM PROPOSES:
─────────────
Query: customers table
Fields: id, name, email, ssn, credit_card
Filter: name = "John Doe"

DATAFENCE CHECKS POLICY:
────────────────────────
✓ Allow: id, name, email
⚠ Redact: ssn (mask with ***)
✗ Block: credit_card (completely denied)

DATAFENCE EXECUTES:
───────────────────
SELECT id, name, email, ssn  -- credit_card removed!
FROM customers
WHERE name = 'John Doe'
  AND tenant_id = 'acme'      -- Added by policy
  AND status = 'active'       -- Added by policy
LIMIT 10                      -- Enforced by policy

DATABASE RETURNS:
─────────────────
{
  "id": "123",
  "name": "John Doe",
  "email": "john@acme.com",
  "ssn": "123-45-6789"
}

DATAFENCE PROTECTS:
───────────────────
{
  "id": "123",
  "name": "John Doe",
  "email": "john@acme.com",
  "ssn": "***-**-****"  // REDACTED!
}

USER SEES:
──────────
"John Doe's account (ID: 123) is active. Email: john@acme.com"

✅ DATA PROTECTED AS PER POLICY!
